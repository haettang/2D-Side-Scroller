# 2D 중력 물리 기반 횡스크롤 게임 멀티 엔진 구현

GameMaker와 Godot을 사용하여 동일한 2D 횡스크롤 액션 게임을 구현한 프로젝트입니다. 플레이어 이동, 전투, 스테이지 진행 및 보스전을 구현하며 2D 게임의 기본적인 게임플레이 시스템을 개발했습니다.

> 이 저장소는 포트폴리오용 코드 아카이브입니다. Godot에서 구현한 핵심 스크립트를 선별하여 공개하며, GameMaker 구현은 엔진의 이벤트 기반 프로젝트 구조 특성상 별도의 코드 파일 형태로 분리하여 공개하지 않습니다.

---

## Project Overview

게임 개발 과정에서 동일한 2D 횡스크롤 게임을 **GameMaker와 Godot에서 각각 구현**했습니다.

하나의 게임을 서로 다른 엔진으로 구현하면서 엔진에서 제공하는 게임 오브젝트 구성 방식과 스크립팅 구조의 차이를 경험하고, 동일한 게임플레이를 각 엔진의 방식에 맞춰 구현했습니다.

게임은 총 6개의 스테이지로 구성되어 있으며, 일반 스테이지 3개와 보스 스테이지 3개를 포함합니다.

---

## Core Gameplay

### 2D Side-Scrolling

플레이어가 횡스크롤 형태의 스테이지를 진행하며 적과 장애물을 상대하고 다음 스테이지로 이동하는 액션 게임입니다.

주요 게임플레이 요소는 다음과 같습니다.

* 플레이어 이동 및 조작
* 적과의 전투
* 스테이지 진행
* 보스전
* 게임 상태 및 스테이지 전환

## Engine Comparison

동일한 게임을 두 가지 엔진에서 구현했습니다.

### GameMaker

GameMaker에서는 게임 오브젝트에 이벤트를 연결하고 각 이벤트 내부에서 로직을 작성하는 **이벤트 중심 구조**가 사용됩니다.

따라서 일반적인 스크립트 파일을 모아 공개하는 방식과 달리, 실제 구현은 다음 요소들의 조합으로 구성되어 있습니다.

```text
Game Object
      ↓
Event
 ├── Create
 ├── Step
 ├── Collision
 ├── Draw
 └── 기타 이벤트
      ↓
Event별 게임 로직
```

이러한 구조와 프로젝트 메타데이터가 서로 연결되어 있기 때문에 원본 GameMaker 프로젝트의 구현을 개별 스크립트 파일로 분리하여 동일한 형태로 공개하기 어렵습니다.

따라서 이 저장소에서는 GameMaker 프로젝트의 코드를 별도로 공개하지 않고, **동일한 게임을 GameMaker에서 구현한 경험과 엔진 구조에 대한 이해**를 프로젝트 설명을 통해 보여줍니다.

### Godot

Godot에서는 게임플레이 로직을 GDScript 기반 스크립트로 분리하여 구현했습니다.

현재 저장소에는 포트폴리오에서 확인할 수 있는 핵심 Godot 스크립트를 선별하여 공개합니다.

## Implementation

Godot 구현에서는 게임플레이에 직접적으로 관련된 기능을 중심으로 코드를 구성했습니다.

주요 구현 영역은 다음과 같습니다.

* 플레이어 제어
* 적 및 보스 동작
* 충돌 및 전투 처리
* 스테이지 진행
* 게임 상태 관리
